1Linear Differential Equations — Basics

A DE is linear if the dependent variable y and its derivatives appear only to the first degree and are never multiplied together.

n-th order linear DE with constant coefficients
dⁿydxⁿ + a1dⁿ⁻¹ydxⁿ⁻¹ + … + an−1dydx + any = X(x)
With D = d/dx (so D² = d²/dx², …) this becomes  f(D) y = X, where f(D) = Dⁿ + a1Dn−1 + … + an is the linear differential operator.
TypeConditionSolution
HomogeneousX = 0y = CF
Non-homogeneousX ≠ 0y = CF + PI  (complete or general solution)
  • CF (complementary function) is the general solution of f(D)y = 0 and contains n arbitrary constants.
  • PI (particular integral) is any one solution of f(D)y = X and contains no arbitrary constants.
  • Superposition: if y1 and y2 solve the homogeneous equation, so does c1y1 + c2y2.
  • y1 and y2 are linearly independent ⇔ the Wronskian W = y1y2′ − y2y1′ ≠ 0.

3Inverse Operator & Particular Integral

PI = 1f(D) X    1DX = ∫X dx    1D − aX = eax∫X e−axdx    1D + aX = e−ax∫X eaxdx

1/f(D) is the inverse of f(D): f(D)[1/f(D)]X = X. The shortcut rules below follow from D eax = a eax and D² sin ax = −a² sin ax.

6PI Type 3 — X = xm (polynomial)

PI = [f(D)]−1 xm  — take the lowest-degree term out, write the rest as [1 ± φ(D)]−1, expand in ascending powers of D up to Dm, then operate term by term.
(1 + z)−1 = 1 − z + z² − z³ + …
(1 − z)−1 = 1 + z + z² + z³ + …
(1 + z)−2 = 1 − 2z + 3z² − 4z³ + …
(1 − z)−2 = 1 + 2z + 3z² + 4z³ + …
If f(D) has no constant term, take out D: 1D(…) means integrate at the end.
Example 1 — (D² + 3D + 2) y = x³ + x²
CF: m = −1, −2 ⇒ c1e−x + c2e−2x.   PI = ½[1 + (3D + D²)/2]−1(x³ + x²) = ½[1 − z + z² − z³](x³ + x²), with z = (3D + D²)/2
⇒ PI = ½x³ − 74x² + 154x − 318  (checked by substitution)
Example 2 — (2D² + 2D + 3) y = x² + 2x − 1
PI = ⅓[1 + (2D + 2D²)/3]−1(x² + 2x − 1) = ⅓[x² + 2x − 1 − (4x + 8)/3 + 8/9] = 13(x² + 2x3 − 259).   General solution: y = e−x/2(c1 cos √5x2 + c2 sin √5x2) + PI.

9Method of Variation of Parameters (VOP)

VOP gives the PI of y″ + p y′ + q y = X (it also works for variable coefficients) once the CF is known.

Step 1: CF = c1y1 + c2y2.   Step 2: Wronskian W = y1 y2
y1′ y2′ = y1y2′ − y2y1′ (≠ 0).   Step 3:
PI = u y1 + v y2,   u = −∫y₂ XWdx,   v = ∫y₁ XWdx
The coefficient of y″ must be 1. Divide through first if it is not.
Equationy1, y2, WResult
y″ + 4y = tan 2xcos 2x, sin 2x; W = 2u = −¼ log(sec 2x + tan 2x) + ¼ sin 2x, v = −¼ cos 2x ⇒ PI = −¼ cos 2x log(sec 2x + tan 2x)
y″ + y = sec xcos x, sin x; W = 1u = log cos x, v = x ⇒ PI = cos x log cos x + x sin x
y″ + y = cosec xcos x, sin x; W = 1PI = −x cos x + sin x log sin x
y″ − 2y′ + y = ex/xex, x ex; W = e2xu = −x, v = log x ⇒ PI = x ex(log x − 1)
Trap
Keep the signs straight: the minus sign goes with u (the integral containing y2). Do not add integration constants. They are already in the CF.

10Equations with Variable Coefficients — Cauchy & Legendre

A suitable substitution reduces these to equations with constant coefficients. Then use CF and PI exactly as before, but in the variable t.

Cauchy–Euler equation
xⁿ y(n) + k1xn−1y(n−1) + … + kny = X
Put x = et (t = log x), θ = d/dt:
xD = θ
x²D² = θ(θ − 1)
x³D³ = θ(θ − 1)(θ − 2)
Legendre's linear equation
k0(ax + b)ny(n) + k1(ax + b)n−1y(n−1) + … + kny = X
Put ax + b = et, θ = d/dt:
(ax + b)D = aθ
(ax + b)²D² = a²θ(θ − 1)
(ax + b)³D³ = a³θ(θ − 1)(θ − 2)

Cauchy's equation is Legendre's equation with a = 1, b = 0. Also convert the RHS: x = et (Cauchy), or x = (et − b)/a (Legendre). Write the final answer back in x.

Example 1 (Cauchy) — x²y″ − xy′ + y = log x
θ(θ − 1) − θ + 1 = (θ − 1)² ⇒ CF = (c1 + c2t)et.   PI = 1(1 − θ)²t = (1 + 2θ + …)t = t + 2.
⇒ y = (c1 + c2 log x)x + log x + 2
Example 2 (Legendre) — (2x + 3)²y″ − 2(2x + 3)y′ − 12y = 6x
2x + 3 = et: 4θ(θ − 1) − 4θ − 12 = 4(θ − 3)(θ + 1);  RHS 6x = 3(et − 3).
CF = c1e3t + c2e−t;   PI = 34[eᵗ−4 − 3−3] = −3eᵗ16 + 34
⇒ y = c1(2x + 3)³ + c₂2x + 3 − 3(2x + 3)16 + 34
Common slip
In Legendre's equation, do not forget the powers of a: (ax + b)²D² = a²θ(θ − 1), not θ(θ − 1). With 2x + 3 the factor is 4.

11Application 1 — Series LCR Circuit

A resistor R (Ω), an inductor L (H), a capacitor C (F) and an EMF E(t) (V) are connected in series. Q is the charge (C) and I = dQ/dt is the current (A).

ElementResistor: RIInductor: L dI/dtCapacitor: Q/C
Kirchhoff's voltage law (sum of voltage drops = applied EMF):
Ld²Qdt² + RdQdt + QC = E(t)   or, in terms of current,   Ld²Idt² + RdIdt + IC = E′(t)
AE: Lm² + Rm + 1/C = 0.   R² > 4L/C: overdamped;  R² = 4L/C: critically damped;  R² < 4L/C: oscillatory (underdamped). Natural frequency ω0 = 1/√(LC).

12Application 2 — Simple Harmonic Motion (Spring–Mass)

A mass m hangs on a spring with stiffness k. At equilibrium mg = ks (s = static stretch). Let x(t) be the displacement from equilibrium, taking downward as positive. Hooke's law gives the restoring force −k(s + x), and Newton's law gives m ẍ = mg − k(s + x) = −kx.

d²xdt² + ω²x = 0,   ω² = km = gs

Common mistakes that cost marks

  • Writing only the PI. The general solution is CF + PI, and the CF must have n constants for an n-th order equation.
  • Not spotting the failure case: always check whether a (or ±ia) is a root of the AE before applying the shortcut.
  • Type 3: expanding past Dm (wasted time) or forgetting the constant factor taken out at the start.
  • Cauchy/Legendre: leaving the final answer in t. Convert back using t = log x or log(ax + b).
  • Applications: using inches instead of feet, and getting the sign of the initial displacement or velocity wrong.
