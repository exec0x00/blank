1Limits, Continuity & Differentiability

A function of two variables z = f(x, y) assigns one real number to each point (x, y) in its domain D. Examples: area A = lb, cylinder volume V = πr²h, potential V = f(x, y, z, t).

Limit

lim(x,y)→(a,b) f(x, y) = L means f → L along every path to (a, b). There are infinitely many paths.
  • Limit does not exist (DNE): find two paths that give different values. Common paths: y = 0, x = 0, y = mx, y = mx².
  • To show a limit exists at the origin, use polar form: x = r cos θ, y = r sin θ. If the result → L as r → 0 for every θ, the limit is L.
  • Polynomials: just substitute. E.g. lim(2,1)(x² − 2xy + 3y² − 4x + 3y − 6) = 4 − 4 + 3 − 8 + 3 − 6 = −8.
Standard examples
(i) 2xy3x² + y² at (0,0): along y = mx → 2m3 + m², which depends on m (y = 0 gives 0, y = x gives ½) ⇒ limit DNE ⇒ not continuous.
(ii) 3x²yx² + y² at (0,0): polar gives 3r cos²θ sin θ → 0 ⇒ limit = 0 exists, but f(0,0) is not defined ⇒ not continuous (the discontinuity is removable).

Continuity

f is continuous at (a, b) if: (1) f(a, b) is defined, (2) the limit exists, and (3) lim(x,y)→(a,b) f = f(a, b). Geometrically, the surface has no hole or tear at that point.

Trap
"Not continuous" does not mean "the limit does not exist". The limit may exist while f(a, b) is undefined or different (example ii).

Differentiability

f is differentiable at (a, b) if Δf = fxh + fyk + ε1h + ε2k, where ε1, ε2 → 0 as (h, k) → (0, 0).

  • Sufficient condition: fx and fy exist and are continuous near (a, b).
  • Differentiable ⇒ continuous. The converse is false.
  • Partial derivatives can exist at a point where f is not continuous. Example: xy/(x² + y²) has fx(0,0) = fy(0,0) = 0, but it is discontinuous at the origin.

2Partial Derivatives

A partial derivative is the derivative with respect to one variable while all the others are held constant.

∂z∂x = zx = fx = limh→0 f(x + h, y) − f(x, y)h    ∂z∂y = zy = fy = limh→0 f(x, y + h) − f(x, y)h

Higher order

NotationMeaning
fxx = ∂²f∂x²,   fyy = ∂²f∂y²Differentiate twice with respect to the same variable.
fxy = ∂²f∂y ∂x = ∂∂y(∂f∂x)Mixed partial: first x, then y. Subscripts read left → right; ∂-notation reads right → left.
  • Clairaut / Schwarz theorem: fxy = fyx when the mixed partials are continuous, so the order does not matter.
  • A function of 2 variables has 2 first-order, 4 second-order and 2n n-th order partial derivatives. A function of m variables has mn of order n.

Geometric interpretation

  • fx(x0, y0) is the slope of the tangent to the curve cut from the surface z = f(x, y) by the plane y = y0 (the x-direction). fy is the slope along the plane x = x0.
  • fxx > 0: the surface is concave up in the x-direction. fyy > 0: concave up in the y-direction.
  • fxy measures how the x-slope changes as we move in the y-direction.
  • Tangent plane at P: z − z0 = fx(x − x0) + fy(y − y0).

3Total Derivative, Differentials & Errors

Total derivative (tree rule)
If z = f(x, y) with x = x(t), y = y(t):   dzdt = ∂z∂xdxdt + ∂z∂ydydt   (add a term for each extra variable).
Total differential
dz = fx dx + fy dy  ⇒  f(a + h, b + k) ≈ f(a, b) + h fx(a, b) + k fy(a, b)
Example — direct
z = x²y³, x = t², y = 2t³: zx = 2xy³ = 16t11, zy = 3x²y² = 12t10.
dzdt = 16t11(2t) + 12t10(6t²) = 104 t12. (Check: z = 8t13.)
Example — approximation
f(2, −3) = 6, fx = 1.3, fy = −0.6. Estimate f(2.1, −3.03):
dz = 1.3(0.1) + (−0.6)(−0.03) = 0.148 ⇒ f ≈ 6.148.

Errors & sensitivity

  • Absolute error ≈ dz; relative error = dz/z; percentage error = 100·dz/z.
  • If u = k xa yb zc, take logs: duu = adxx + bdyy + cdzz, so percentage errors add with the powers as weights.
  • Cylinder tank (h = 10, r = 2): dV = 2πrh dr + πr²dh = 40π dr + 4π dh. The volume is about 10× more sensitive to the radius than to the height.

4Chain Rule & Composite Functions

If z = f(x, y), x = g(u, v), y = h(u, v):
∂z∂u = ∂z∂x∂x∂u + ∂z∂y∂y∂u    ∂z∂v = ∂z∂x∂x∂v + ∂z∂y∂y∂v
Draw the tree diagram: multiply along each branch and add over all branches that end at the variable.

Polar substitution results (x = r cos θ, y = r sin θ)

  • u = f(x² + y²) (for example sin(x² + y²) or ex²+y²) ⇒ ∂u∂θ = 0, because u depends only on r.
  • u = tan−1(y/x) ⇒ uθ = ux(−r sin θ) + uy(r cos θ) = r²(sin²θ + cos²θ)/r² = 1.
  • u = x²y + yz², with x = r cos θ, y = r sin θ, z = θ ⇒ uθ = 2xy(−r sin θ) + (x² + z²)(r cos θ) + 2yz.
  • Identity: (ux)² + (uy)² = (ur)² + 1r²(uθ)².
Example — one-variable chain
u = exy·(stuff) problems: always write dudt = uxx′ + uyy′, then substitute x(t) and y(t) at the end. E.g. u = exy + ln(y² + 1), x = tan t, y = cos t: dudt = y exy sec²t + (x exy + 2yy² + 1)(−sin t).

6Homogeneous Functions & Euler's Theorem

Definition
u = f(x, y) is homogeneous of degree n if  f(λx, λy) = λn f(x, y), or equivalently u = xn g(y/x) = yn g(x/y). For three variables: u = xn g(y/x, z/x). The degree n can be positive, negative, zero or a fraction.
Euler's theorem
x ux + y uy = n u
x ux + y uy + z uz = n u  (3 variables)
Corollary (second order)
x²uxx + 2xy uxy + y²uyy = n(n − 1) u
Modified Euler — f(u) homogeneous, u not
If f(u) is homogeneous of degree n:
x ux + y uy = n f(u)f′(u) = g(u)
x²uxx + 2xy uxy + y²uyy = g(u)[g′(u) − 1]
  • A constant has degree 0; linear functions have degree 1. In thermodynamics, extensive variables have degree 1 and intensive variables degree 0. Euler's theorem is also used in economics (production functions).
  • Degree checks from the slides: (x⁴ + 2x²y² + y⁴)/(x² + y²)² → 0;   sin−1(y/x)/√(x² + y²) → −1;   (x²y + xy²)/(x + y)³ → 0;   (ex − ey)/(x − y) → not homogeneous.

7Taylor's & Maclaurin's Series

One variable (review)

f(x) = f(a) + (x − a) f′(a) + (x − a)²2!f″(a) + … ; with a = 0 this is Maclaurin's series.

ex = 1 + x + x²/2! + x³/3! + …sin x = x − x³/3! + x⁵/5! − …cos x = 1 − x²/2! + x⁴/4! − …
log(1 + x) = x − x²/2 + x³/3 − … (|x| < 1)sinh x = x + x³/3! + x⁵/5! + …cosh x = 1 + x²/2! + x⁴/4! + …
(1 + x)n = 1 + nx + n(n−1)2!x² + …tan−1x = x − x³/3 + x⁵/5 − …sin−1x = x + 12x³3 + 1·32·4x⁵5 + …

Two variables — about (a, b), with h = x − a, k = y − b

f(x, y) = f(a, b) + 11![h fx + k fy] + 12![h²fxx + 2hk fxy + k²fyy] + 13![h³fxxx + 3h²k fxxy + 3hk²fxyy + k³fyyy] + …

All derivatives are evaluated at (a, b). Compact form: f(a + h, b + k) = Σ 1n!(h∂x + k∂y)n f(a, b), with binomial coefficients 1-2-1 and 1-3-3-1.

Maclaurin (a = b = 0): f(x, y) = f(0,0) + [x fx + y fy] + 12![x²fxx + 2xy fxy + y²fyy] + …
Working rule
Make a table: f, fx, fy, fxx, fxy, fyy (and the third-order derivatives if asked), each with its value at (a, b), then substitute. "Expand in powers of (x − 1) and (y + 2)" means a = 1, b = −2.

8Maxima & Minima (two variables)

f(a, b) is a relative maximum if f(a, b) > f(a + h, b + k) for all small h, k (Δ = f(a + h, b + k) − f(a, b) < 0), and a relative minimum if Δ > 0. Maxima and minima together are called extreme values. A saddle point is a stationary point that is neither.

Second-derivative test
Stationary points: solve fx = 0 and fy = 0. Let r = fxx, s = fxy, t = fyy. Then rt − s² = det of the Hessian [[fxx, fxy], [fyx, fyy]].
rt − s²rNature of (a, b)
> 0< 0Maximum
> 0> 0Minimum
< 0anySaddle point (not an extremum)
= 0—Doubtful: the test fails, investigate further
Memory hook
"r negative ⇒ max, like f″ < 0 in one variable." Always check the sign of rt − s² first.

9Lagrange's Method of Undetermined Multipliers

Use this method to find the extremum of f(x, y, z) subject to a constraint φ(x, y, z) = 0.

Working procedure
1. Form F = f + λφ (λ is the Lagrange multiplier).
2. Solve Fx = 0, Fy = 0, Fz = 0 together with φ = 0 (4 equations in x, y, z, λ).
3. Trick: write λ from each equation and equate, for example λ = −yz/(2x) = −xz/(2y) ⇒ x² = y². Then substitute into φ.
Advantages: stationary values are found without solving for the variables explicitly at every step, and the method extends to many variables and constraints.
Disadvantages: it does not tell whether a point is a max or a min (use physical reasoning), and the conditions Fx = Fy = Fz = 0 are only necessary conditions.

Standard results

Rectangular solid of max volume inscribed in a sphere x² + y² + z² = a²V = 8xyz, φ = x² + y² + z² − a². 8yz + 2λx = 0, etc. ⇒ x² = y² = z² ⇒ cube, side 2a/√3, Vmax = 8a³/(3√3)
Points on x² − z² = 1 closest to the originf = x² + y² + z²: 2x(1 + λ) = 0, 2y = 0, 2z(1 − λ) = 0. x ≠ 0 ⇒ λ = −1 ⇒ z = 0 ⇒ (±1, 0, 0), distance 1

Two paths give different limits ⇒ DNE. Polar form r → 0 to prove existence.
Continuous ⇔ lim = f(a, b). Differentiable ⇒ continuous. Partial derivatives existing does not imply continuity.

Common mistakes that cost marks

  • Mixing up fxy (first ∂x, then ∂y) with ∂²f/∂x∂y (first ∂y). The answer is the same when the partials are continuous, but state it correctly.
  • In implicit differentiation, forgetting the minus sign in −fx/fy.
  • Applying Euler to u when only f(u) is homogeneous. Always test the degree with λ first.
  • Not converting units (inches → feet, degrees → radians) in rate and error problems.
  • Max/min: forgetting to list all stationary points (factor completely, consider every case such as y = 0 or x = 5) and to state the max/min value, not just the point.
  • Taylor: forgetting the factor 2 in 2hk fxy and the 1/2! in front of the bracket.
Exam-hall checklist
✔ Write the formula first (it earns step marks)   ✔ Draw a tree diagram for chain-rule questions   ✔ Make a derivative table for Taylor and max/min   ✔ Box the final answer with units.
