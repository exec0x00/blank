T4 · Rotational (microwave) spectroscopy

F3 · Spectroscopic activity checker

  1. Permanent dipole? → Yes: microwave (rotational) active
  2. Dipole changes during a vibration? → Yes: IR active
  3. All molecules → electronic (UV-Vis) active
  4. HCl: all three · CO: all three · H₂, Cl₂: electronic only · CO₂: IR (asym. stretch, bend) + electronic, not microwave · H₂O: all three · HI: all three

F4 · Rotational spectrum → bond length

  1. Read first line (or spacing) → B = line/2
  2. I = h / (8π²cB)
  3. μ = m₁m₂/(m₁+m₂) in kg
  4. r₀ = √(I/μ)

T5 · Vibrational (IR) – SHO

F5 · IR line → force constant (and reverse)

  1. ν̄ → k = 4π²c²ν̄²μ
  2. k → ν̄ = (1/2πc)√(k/μ) → ZPE = ½ν̄ → ε_v = (v+½)ν̄

T6 · Vibrational – anharmonic

F6 · Anharmonic solver

  1. fundamental = ω̄ₑ(1−2xₑ); overtone = 2ω̄ₑ(1−3xₑ)
  2. ratio overtone/(2·fund) = (1−3xₑ)/(1−2xₑ) → xₑ
  3. ω̄ₑ = fundamental/(1−2xₑ)

T7 · Electronic spectroscopy & Franck–Condon

F7 · Franck–Condon outcome

  1. Compare rₑ′ with rₑ″
  2. Equal → (0,0) strongest
  3. Longer → (v′,0), v′>0 strongest
  4. Much longer → continuum (dissociation)

M2 · Phase Equilibria

T8 · Basic terms & phase rule

F9 · Phase-rule application

  1. Count P
  2. Count C (minimum constituents)
  3. Gas absent & constant pressure? → F=C−P+1, else F=C−P+2
  4. Classify F=2 bivariant, 1 univariant, 0 invariant

T9 · Derivation of phase rule

F8 · Phase-rule derivation

  1. Variables = P(C−1)+2
  2. Constraints = C(P−1)
  3. F = variables − constraints = C−P+2

T11 · Two-component: reduced phase rule & Pb–Ag

F10 · Pb–Ag cooling path

  1. Melt cools → Pb separates, melt gets richer in Ag along curve to O
  2. At O (303 °C): Pb + Ag + melt, F=0
  3. Below O: solid Pb + solid Ag

F11 · Thermal analysis → phase diagram

  1. Cool melts of several compositions
  2. Record T vs time
  3. Read break & halt temperatures
  4. Plot vs composition → diagram
