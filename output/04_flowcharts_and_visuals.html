T4

Rotational (microwave) spectroscopy

★★★

F3Spectroscopic activity checker

  1. 1Permanent dipole? → Yes: microwave (rotational) active
  2. 2Dipole changes during a vibration? → Yes: IR active
  3. 3All molecules → electronic (UV-Vis) active
  4. 4HCl: all three · CO: all three · H₂, Cl₂: electronic only · CO₂: IR (asym. stretch, bend) + electronic, not microwave · H₂O: all three · HI: all three

F4Rotational spectrum → bond length

  1. 1Read first line (or spacing) → B = line/2
  2. 2I = h / (8π²cB)
  3. 3μ = m₁m₂/(m₁+m₂) in kg
  4. 4r₀ = √(I/μ)

★★★

F6Anharmonic solver

  1. 1fundamental = ω̄ₑ(1−2xₑ); overtone = 2ω̄ₑ(1−3xₑ)

T7

Electronic spectroscopy & Franck–Condon

★★★

F7Franck–Condon outcome

  1. 1Compare rₑ′ with rₑ″
  2. 2Equal → (0,0) strongest
  3. 3Longer → (v′,0), v′>0 strongest
  4. 4Much longer → continuum (dissociation)

T8

Basic terms & phase rule

★★★

F9Phase-rule application

  1. 1Count P
  2. 2Count C (minimum constituents)
  3. 3Gas absent & constant pressure? → F=C−P+1, else F=C−P+2
  4. 4Classify F=2 bivariant, 1 univariant, 0 invariant
T9

Derivation of phase rule

★★★

F8Phase-rule derivation

  1. 1Variables = P(C−1)+2
  2. 2Constraints = C(P−1)
  3. 3F = variables − constraints = C−P+2
