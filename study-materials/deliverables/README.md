# PESU study documents

This folder contains note-first unit masters and per-video PDF/HTML documents, grouped by course and unit. Lesson PDFs use authored or edited topic notes with citations; slide screenshots are not embedded as the lesson.

Open each document's `index.html` in a browser. Its neighboring `assets/` directory contains the diagrams, figures, and fonts used by the page. The neighboring PDF is the print copy. Keep the HTML and assets together.

All documents are marked DRAFT. Transcript/audio, source attribution, formula interpretation, and page-level visual/semantic review remains incomplete. `deliverables-index.json` records each file path, SHA-256, PDF page count, and asset inventory. Reusable note content is in `datasets/study-notes-dataset.json`; complete source point text, formula candidates, visual-page locators, transcripts, and question records are preserved in sibling datasets under `study-materials/`.
