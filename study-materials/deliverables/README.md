# PESU study documents

This folder contains the generated unit master and per-video PDF/HTML documents, grouped by course and unit.

Open each document's `index.html` in a browser. Its neighboring `assets/` directory contains the diagrams, figures, and fonts used by the page. The neighboring PDF is the print copy. Keep the HTML and assets together.

All documents are marked DRAFT. Transcript/audio, source attribution, formula interpretation, and page-level visual/semantic review remains incomplete. `deliverables-index.json` records each file path, SHA-256, PDF page count, and asset inventory. The source datasets and Forge packs are in sibling folders under `study-materials/`.
