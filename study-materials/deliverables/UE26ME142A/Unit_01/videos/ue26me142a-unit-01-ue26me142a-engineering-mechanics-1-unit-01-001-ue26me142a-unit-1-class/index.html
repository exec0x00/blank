A particle is defined as an object which occupies a single point in space which has mass, which has negligible dimension.

Key details

  • With respect to naked eyes.
  • Of course, when you go to nano level, you can certainly measure the dimensions of a particle.
  • Point which is occupied by the object in space, one single point.

  • Then when we say it has mass, the particle will settle down.
  • Then it is very tiny and we cannot measure it with the naked eyes.
  • Such objects are defined as particles.
  • Next, the three different types of bodies.
  • What is a rigid body?
  • A rigid body is one in which when we apply force onto this, there is no change in shape and size of the body.
  • Such bodies are defined as rigid body.
  • Next, elastic body.
  • What is an elastic body?
  • When a force is applied on an elastic body, it changes its shape and size.
  • But on removal of the force causing this change, the body will regain its original shape and size.
  • Such bodies are called as elastic bodies.
  • Next is a plastic body.
  • What is a plastic body?
  • A plastic body is one.
  • Which will change its shape and size on application of a force, but it will not regain its original shape and size.
  • Such bodies are called as plastic bodies.
  • Next, how do we define a force?
  • A force is something which changes the state of rest of uniform motion of an object.
  • If the object or the body is already in motion, it can stop that motion or it can increase the speed of the body or it can reduce the speed of the body.
  • For such application or such thing is called as a force.
  • Now, next comes what are the different types of forces.
  • Forces can be broadly divided into two types.
  • Forces which are having forces which are in one plane, coplanar forces.
  • The other one is non-coplanar forces.
  • Which can be represented only along two dimensions.
  • Non-co-planar forces are forces which can be represented along all the three coordinate systems that is required.
  • Concurrent forces and non-concurrent forces.
  • What are concurrent forces?
  • Concurrent forces are forces which will have the same point of application.
  • Non-concurrent forces which will have different points of application.
  • Under non-concurrent force system, we can have parallel force system and non-parallel force system.
  • Under parallel force system, all the forces are going to be parallel to each other.
  • Non-parallel force system, they need not have to be parallel.
  • Under parallel force system, we can have two categories.
  • One is like parallel force system and unlike parallel force system.
  • What is like parallel force system?
  • Like parallel force system, where the sense of the force are same for all.
  • Unlike parallel force system, the sense of the forces are different.
