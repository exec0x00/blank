Core explanation · 00:00–04:59

Today we are going to explore Pillow, the modern version of Python Imaging Library, also called PIL.

Key details

  • Simple and powerful library that helps us open images, edit images, and save images in multiple formats.
  • It specially deals with image processing tasks.
  • Pillow is widely used because it is easy to understand, support many image formats, and includes built-in functions for tasks like resizing, cropping, rotating and filtering images.
  • To install Pillow module, we simply use Pip install pillow.
  • To start with below, we first import the image class.
  • Here's a basic code to open an image and display it on the screen.
  • Image.show displays it using your system's default viewer.
  • Pillow supports JPEG, PNG, BMP, JIF, TIF, and many more image formats.
  • Once we load the image, we can check some important details like format, which tells the file type like JPEG, or GIF, or Tiv, etc.
  • Then the size, which gives the width and height in pixels.
  • Then the mode shows the colour representation such as RGB or grayscale.
  • These properties help us understand the image before processing it.
  • Resizing is one of the most common operations in image processing.
  • Here's how we resize an image.
  • But it may distort the aspect ratio.
  • To maintain the aspect ratio we can use thumbnail.
  • This ensures the image is resized without stretching or squashing.
  • converting the image modes.
  • You can use convert function to convert to an image to a different colour mode.
  • The common colour modes are one, which is pure black and white, it's just one bit.
  • L, which is grayscale.
  • All the shades of gray colour will be represented in an 8-bit representation.
  • Then RGB, red, green, blue colour, three channels, and this is also an 8-bit representation.
  • Red, green, blue, and A stands for alpha, which is represents the transparency.
  • Then C M Y K, which stands for Syan, Majenta, Low, and Black.
  • Mostly used in printing.
  • Mode conversion is especially useful in machine learning preprocessing, where special formats are required.
  • To save an image that you have worked on, you can use save function.
  • Then to rotate an image, you can use rotate function and give the degrees as argument.
