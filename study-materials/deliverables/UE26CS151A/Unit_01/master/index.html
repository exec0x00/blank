Computational problem solving is a process, not just coding. Begin by understanding the goal and constraints, then represent the problem, choose a method, implement it in Python, and test the result against cases that matter.

3Man Cabbage Goat Wolf Problem

Study focus: Man Cabbage Goat Wolf Problem. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000010 · EV0000011

short-note recap

Model the river puzzle as a state-space search. The farmer, wolf, goat, and cabbage begin on one bank. The boat carries the farmer plus at most one passenger. A state records which bank each item occupies.

A state is unsafe if the farmer leaves the wolf alone with the goat, or the goat alone with the cabbage. A legal move changes the farmer's bank and optionally moves one item with him; reject any move that creates an unsafe state.

Search the remaining legal states until the goal is reached, and keep a record of visited states to avoid cycling. The key computational idea is to make constraints explicit, generate only valid successors, and verify that the final state satisfies the goal.

short-note recap

Hardware is the physical machine; software is the instructions and data it uses. A computer accepts input, stores and processes data, and produces output. The processor executes instructions, memory holds active data and programs, and input/output devices connect the computer to its environment.

Operating-system software manages hardware resources and provides services to applications. Application software performs tasks for a user. A program is not the hardware itself: it is a representation of operations that the machine executes.

Distinguish primary memory, which the processor can access directly while programs run, from persistent secondary storage. The distinction helps explain where instructions and data reside at each stage of computation.

7Computer hardware

Study focus: Computer hardware. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000074 · EV0000075

short-note recap

A digital computer processes encoded data through coordinated components. The input unit supplies data and instructions; memory stores them; the processor fetches and executes instructions; and output devices present results. The arithmetic and logic unit performs calculations and comparisons, while the control unit coordinates instruction execution.

Registers and main memory are fast working storage but are volatile: their contents normally disappear when power is removed. Secondary storage such as an SSD retains files. The processor does not directly understand a human problem; software encodes the steps and data in forms the machine can process.

When tracing a program, follow both the changing values in memory and the sequence of instructions executed by the processor.

short-note recap

A Python program is built from statements and expressions arranged with meaningful indentation. A statement performs an action, such as assigning a value or calling a function; an expression produces a value. Names identify variables and functions, while literals provide fixed values.

Indentation is part of Python's syntax: statements at the same indentation level belong to the same block, and a block follows a header ending in a colon. Comments explain intent to a human reader but are ignored by Python.

11print function

short-note recap

print() writes a readable representation of values to standard output. It can display one value or several values separated by commas. The sep argument controls the text between values, and end controls what is written after them; by default, values are separated by a space and the call ends with a newline.

Strings need quotation marks in source code, but print() displays their contents without those delimiters. Printing is useful for user-facing output and for tracing a program while debugging.

Remember that printing a value is different from returning it from a function. Output is text sent to the terminal; a returned value can be used by later expressions.

short-note recap

A variable name refers to a value used by a program. Assignment evaluates the right-hand expression and binds the resulting value to the name on the left. Later assignment can bind that same name to another value.

Python is dynamically typed: the type belongs to the object, and a name can refer to objects of different types at different points in a program. Choose names that describe their role, and do not confuse the name with the storage location or with the value itself.

When tracing code, update a name's binding after each assignment. This simple state trace exposes errors caused by using an old or unexpected value.

short-note recap

Assignment binds a name to an object; it does not copy an object's identity into the name. The built-in id(x) returns an integer that is unique and constant for that object's lifetime. In CPython it often corresponds to a memory address, but Python code should not rely on that implementation detail.

Use == to compare values for equality. Use is only when object identity is what matters, most commonly to test a singleton such as None. Two separate objects can compare equal while having different identities.

For mutable objects, two names may refer to the same object; changing it through either name is visible through both. This is why identity and value equality must be kept distinct.

17Bitwise operators

Study focus: Bitwise operators. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000222 · EV0000223

short-note recap

Bitwise operators act on the binary representation of integers. AND keeps a bit only when both corresponding bits are 1; OR keeps it when either is 1; XOR keeps it when the bits differ; complement inverts the representation under Python's integer model. Left and right shifts move bit positions and correspond to multiplication or floor division by powers of two for nonnegative integers.

Bitwise operations are useful for masks, flags, and low-level encodings. They are different from Boolean and, or, and not, which work with truth values and short-circuit evaluation.

Write small binary examples before combining masks; the bit-by-bit view is the safest way to check a result.

Boolean logic combines conditions. not negates truth, and is true only when both operands are truthy, and or is true when at least one is truthy. Python evaluates and and or from left to right and may stop as soon as the result is determined.

With A and B, Python skips B if A is false. With A or B, it skips B if A is true. This short-circuit rule supports safe guards such as checking that a value is not None before using it.

These operators return one of their operands, not necessarily a Boolean. Use explicit comparisons when the code's intent would otherwise be unclear.

short-note recap

Expressions evaluate to values. A literal such as 123, 3.5, or a string is already an expression. A variable name is also an expression because evaluating the name retrieves its current value. Operators combine operands to build larger expressions.

Operators and operands. A unary operator acts on one operand, a binary operator on two, and Python's conditional expression has three parts: value_if_true if condition else value_if_false. Parentheses explicitly group a subexpression.

Precedence chooses which operation binds first. In 2 + 3 * 4, multiplication has higher precedence, so Python evaluates 3 * 4 first and returns 14. Parentheses can override the default grouping; use them when the intended order should be obvious to a reader.

Associativity breaks ties. Operators at the same precedence level follow their associativity rule. Subtraction groups left to right, so 10 - 3 - 2 means (10 - 3) - 2 = 5. Exponentiation groups right to left, so 2 ** 3 ** 2 means 2 ** (3 ** 2) = 512. Do not assume every operator groups in the same direction.

Where the result appears. The interactive interpreter echoes the value of a bare expression. A saved .py program needs print(expression) when the result should appear in the terminal.

short-note recap

Sequential control runs statements in order; selection chooses a branch. Python executes a block from top to bottom unless a control statement changes the path. An if/elif/else chain evaluates conditions in order and executes the first matching branch.

21iterative control structure

Study focus: iterative control structure. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000302 · EV0000303

short-note recap

Iteration repeats a block while progressing toward a stopping condition. A for loop visits items from an iterable; a while loop repeats as long as its condition is true. For each loop, identify initialization, the repeated work, the state update, and the exit condition.

A for loop is often the clearest choice when processing a known collection or range. A while loop is useful when the number of repetitions depends on a changing condition. Make sure every path through a while-loop body moves toward termination.

break exits the nearest loop and continue skips to its next iteration. Use them sparingly so the loop's flow remains easy to trace.

22String Operations

Study focus: String Operations. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000322 · EV0000323

short-note recap

A Python string is an immutable sequence of Unicode characters. Indexing selects one character, slicing selects a half-open range, and concatenation combines strings. A slice s[a:b] includes index a and stops before index b.

Common methods return new strings: lower() changes letter case, strip() removes edge whitespace, and split() separates text into a list. Because strings are immutable, a method does not modify the original string in place.

Check index boundaries and empty strings when processing input. For readable output that mixes text and values, use formatted string literals rather than manual concatenation.
