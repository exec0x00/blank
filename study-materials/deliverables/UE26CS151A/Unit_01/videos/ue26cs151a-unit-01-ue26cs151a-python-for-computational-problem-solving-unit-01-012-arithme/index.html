1Arithmetic, membership and relational operators

Study focus: Arithmetic, membership and relational operators. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000198 · EV0000199

short-note recap

Operators combine operands to compute or test values. Arithmetic operators perform numeric operations; relational operators such as <, ==, and >= compare values and produce a Boolean result; membership operators in and not in test whether a value occurs in a collection or string.

Keep the result type in mind: 5 > 2 is a Boolean, while 5 + 2 is numeric. Division with / produces a floating-point result in Python, even when both inputs are integers; // is floor division.

Use parentheses to make mixed expressions easy to read, and test boundary cases for comparisons.
