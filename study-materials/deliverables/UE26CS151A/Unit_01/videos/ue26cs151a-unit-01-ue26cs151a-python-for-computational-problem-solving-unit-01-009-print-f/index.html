1print function

Study focus: print function. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000130 · EV0000131

short-note recap

print() writes a readable representation of values to standard output. It can display one value or several values separated by commas. The sep argument controls the text between values, and end controls what is written after them; by default, values are separated by a space and the call ends with a newline.

Strings need quotation marks in source code, but print() displays their contents without those delimiters. Printing is useful for user-facing output and for tracing a program while debugging.

Remember that printing a value is different from returning it from a function. Output is text sent to the terminal; a returned value can be used by later expressions.
