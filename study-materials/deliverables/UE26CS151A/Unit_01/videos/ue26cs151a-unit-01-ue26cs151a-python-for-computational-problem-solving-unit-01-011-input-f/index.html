1input function

Study focus: input function. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000182 · EV0000183

short-note recap

input() reads a line of text and returns it as a string. A prompt can be supplied to tell the user what to enter, but the returned value is still text. Convert it before arithmetic: use int() for an integer or float() for a decimal quantity, and handle invalid input when the program requires robustness.

Separate reading, conversion, validation, and computation. This makes it clear whether a failure came from unexpected text, an out-of-range value, or the algorithm itself.

Do not assume that typing digits makes the result numeric: input() returns a string until the program explicitly converts it.
