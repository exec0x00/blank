1sequential, selection control

Study focus: sequential, selection control. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000286 · EV0000287

short-note recap

Sequential control runs statements in order; selection chooses a branch. Python executes a block from top to bottom unless a control statement changes the path. An if/elif/else chain evaluates conditions in order and executes the first matching branch.

Write conditions that cover the intended cases without overlap where possible. Put the most specific conditions before broader ones, and include an else branch when every remaining case needs a defined response.

Indentation marks each branch's body. Trace a few inputs by recording which condition is tested and which statements run; this is more reliable than guessing from the visual layout.
