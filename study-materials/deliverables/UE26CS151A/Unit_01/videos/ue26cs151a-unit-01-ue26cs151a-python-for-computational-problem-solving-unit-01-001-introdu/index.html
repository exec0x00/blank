1Introduction

Study focus: Introduction. The notes explain the key terms, distinctions, and practical method used in this lesson. Read the cited transcript intervals for source context, then use the examples to check your understanding. EV0000002 · EV0000003

short-note recap

Computational problem solving is a process, not just coding. Begin by understanding the goal and constraints, then represent the problem, choose a method, implement it in Python, and test the result against cases that matter.

Keep the problem statement separate from the program. A computer follows exact instructions; it does not infer missing requirements. Use examples to clarify input, output, and edge cases before writing code.

Python can be used interactively to explore an expression or in a saved .py file for a repeatable program. The course connects algorithmic reasoning to syntax, data, control flow, and testing; each later topic supplies a tool in that larger process.
