Worked examples

W000001 · Apply precedence and associativity
givenEvaluate 2 + 3 * 4, 10 - 3 - 2, and 2 ** 3 ** 2.
methodApply Python operator precedence and associativity.
step 1Multiplication precedes addition: 2 + (3 * 4) = 14.
step 2Subtraction is left associative: (10 - 3) - 2 = 5.
step 3Exponentiation is right associative: 2 ** (3 ** 2) = 512.
step 4Parentheses make each grouping explicit and are useful even when the default rule is known.
answer14, 5, and 512, respectively.
unitsDimensionless integers.
checkThe results follow Python's operator precedence table and documented associativity rules; no source slide value has been assumed.

short-note recap

Expressions evaluate to values. A literal such as 123, 3.5, or a string is already an expression. A variable name is also an expression because evaluating the name retrieves its current value. Operators combine operands to build larger expressions.

Operators and operands. A unary operator acts on one operand, a binary operator on two, and Python's conditional expression has three parts: value_if_true if condition else value_if_false. Parentheses explicitly group a subexpression.

Precedence chooses which operation binds first. In 2 + 3 * 4, multiplication has higher precedence, so Python evaluates 3 * 4 first and returns 14. Parentheses can override the default grouping; use them when the intended order should be obvious to a reader.

Associativity breaks ties. Operators at the same precedence level follow their associativity rule. Subtraction groups left to right, so 10 - 3 - 2 means (10 - 3) - 2 = 5. Exponentiation groups right to left, so 2 ** 3 ** 2 means 2 ** (3 ** 2) = 512. Do not assume every operator groups in the same direction.

Where the result appears. The interactive interpreter echoes the value of a bare expression. A saved .py program needs print(expression) when the result should appear in the terminal.
