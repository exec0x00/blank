1Homogeneous functions

Definitions

Homogeneous function (two variables). A function u=f(x,y) is said to be a homogeneous function of degree n if it can be expressed in the form xng(xy​) or yng(yx​), g being an arbitrary function. S005·3 · T005 00:02:45
Homogeneous function (three variables). u=f(x,y,z) is homogeneous of degree n if it can be expressed as xng(xy​,xz​), or yng(yx​,yz​), or zng(zx​,zy​). S005·4 · T005 00:04:38
Scaling test. f is homogeneous of degree n exactly when f(tx,ty)=tnf(x,y) for all t>0: scaling every variable by t scales the function by tn. added for clarity S005·5
Degree. The power n in xng(y/x); for a polynomial whose terms all have the same total degree, that common degree. T005 00:01:31

Key points

  1. For a polynomial, check that every term has the same total degree; that is the degree (x3+3x2y+3xy2+y3: degree 3). ESA ★★ T005 00:01:15 · T005 00:01:31
  2. To test any function: take out xn (or yn) and check that what remains depends only on y/x (and z/x). ESA ★★ S005·3 · T005 00:05:42
  3. Either form, xng(y/x) or ynh(x/y), may be used — whichever is convenient — and both give the same degree. ESA ★★ T005 00:04:01
  4. Inverse trigonometric or exponential functions of a homogeneous expression are usually not homogeneous; first find an f with f(u) homogeneous (topic 4). ESA ★★★ T005 00:01:47 · T005 00:02:04
  5. Homogeneous functions appeared earlier in homogeneous differential equations, solved by y=vx. ESA ★ transcript only T005 00:00:22

Exam traps

Exam trap. The lecture says the converse holds: “a function of degree 0 should be a constant function”. It does not: y/x, sin−1(y/x) and x+yx−y​ all have degree 0 and are not constant. added for clarity T005 00:07:11
Exam trap. “Homogeneous” does not mean “smooth everywhere” (as said at T005 00:11:06); it is a scaling property. (x​+y​)/(x+y) is homogeneous but not defined at the origin. added for clarity T005 00:11:06

2Euler's theorem

Statements in the class material

“Statement 1: If u=f(x,y) is a homogeneous function of degree n then x∂x∂u​+y∂y∂u​=nu.” S005·6
“Statement 2: If u=f(x,y,z) is a homogeneous function of degree n then x∂x∂u​+y∂y∂u​+z∂z∂u​=nu.” S005·6

Key points

  1. You do not need to differentiate: check that u is homogeneous, find n, and write xux​+yuy​=nu. ESA ★★★ T005 00:09:17 · T005 00:17:32
  2. The lecturer calls Euler's theorem “the most important one” of the session. ESA ★★★ T005 00:08:57
  3. Check: u=x2+y2 gives x(2x)+y(2y)=2u, degree 2. ESA ★★ T005 00:10:31
  4. Meaning: the change along x scaled by x, plus the change along y scaled by y, equals the function scaled by its degree. ESA ★ T005 00:09:46 · T005 00:11:24

Why?

Why is xux​+yuy​=nu? (A short proof.)
Differentiate u(tx,ty)=tnu(x,y) with respect to t using the chain rule: xux​(tx,ty)+yuy​(tx,ty)=ntn−1u(x,y). Put t=1.
added for clarityS005·6

3Second and higher order: the corollary

Statements in the class material

“Corollary 1: If u=f(x,y) is a homogeneous function of degree n then x2∂x2∂2u​+2xy∂x∂y∂2u​+y2∂y2∂2u​=n(n−1)u.” S005·6

Key points

  1. The mixed partials uxy​ and uyx​ are equal here (continuous derivatives), which is why the middle term is 2xyuxy​. ESA ★★ T005 00:12:04
  2. For u=u1​+u2​ with different degrees n1​,n2​, apply the results to each part: x2uxx​+⋯=n1​(n1​−1)u1​+n2​(n2​−1)u2​. ESA ★★★ added for clarity ESA Jan-24 s3 1c · CW U1 P22
  3. Extend to three or more variables as an exercise; the lecture leaves it open and points to a research paper on higher-order extensions. ESA ★ S005·6 · T005 00:14:59

Why?

Why is the second-order right side n(n−1)u?
ux​ and uy​ are homogeneous of degree n−1, so Euler's theorem applied to them gives xuxx​+yuxy​=(n−1)ux​ and xuyx​+yuyy​=(n−1)uy​. Multiply by x and y, add, and use xux​+yuy​=nu.
added for clarityS005·6

4Extension: when f(u) is homogeneous

Statements in the class material

“If f(u) be a homogeneous function of degree n in x and y, then x∂x∂u​+y∂y∂u​=nf′(u)f(u)​ and x2∂x2∂2u​+2xy∂x∂y∂2u​+y2∂y2∂2u​=g(u)[g′(u)−1] where g(u)=nf′(u)f(u)​.” S005·7

Key points

  1. Spot the extension case: u=sin−1(…), tan−1(…), log(…) or e(…) of a homogeneous expression; then f is sin, tan, exp or log respectively. ESA ★★★ added for clarity S005·7 · ESA May-24 1a
  2. The degree n belongs to f(u), not to u. ESA ★★★ S005·7

Why?

Where does nf(u)/f′(u) come from?
Apply Euler to F=f(u): xFx​+yFy​=nF. By the chain rule Fx​=f′(u)ux​, Fy​=f′(u)uy​, so f′(u)(xux​+yuy​)=nf(u).
added for clarityS005·7

Exam traps

Exam trap. For u=tan−1xyx4+y4​ the degree is that of tanu=xyx4+y4​, i.e. 4−2=2, not of u. added for clarity ESA May-24 1a

5Applications of homogeneous functions

Definitions

Extensive / intensive variable. Extensive variables (mass, volume, energy) double when the system is doubled: homogeneous of degree 1. Intensive variables (pressure, temperature, density) do not change: degree 0. added for clarity S005·5 · T005 00:16:26

Statements in the class material

“A constant function is homogeneous of degree 0. Linear functions are homogeneous of degree 1. The degree of the homogeneous function can be positive, negative or zero.” S005·5

Key points

  1. A constant function is homogeneous of degree 0; linear functions are homogeneous of degree 1. ESA ★ S005·5 · T005 00:06:52
  2. Euler's theorem also describes the scaling of the function: nu. ESA ★ S005·5 · T005 00:15:57
  3. Applications: production functions, marginal productivities and elasticity of demand in economics; extensive (degree 1) and intensive (degree 0) variables in thermodynamics. ESA ★ S005·5 · T005 00:16:09
  4. Any function of ratios only, such as f(x/y,y/z,z/x), has degree 0, so xux​+yuy​+zuz​=0 (ESA Jan 2024 set 1). ESA ★★★ added for clarity ESA Jan-24 s1 1d

Exam traps

Exam trap. The lecture swaps the examples: mass is extensive (degree 1); pressure and temperature are intensive (degree 0). added for clarity T005 00:16:46
